Boîtes à classer

Un logiciel gratuit pour apprendre à classer les êtres vivants dans des boîtes emboîtées, selon les attributs qu'ils partagent.

Sans rien installer : le logiciel fonctionne directement dans le navigateur, sur ordinateur ou tablette.

Utiliser en ligne

Télécharger

Windows votre système

  1. Décompresser le fichier zip.
  2. Double-cliquer sur Boites-a-classer.exe.

Si Windows affiche « Windows a protégé votre ordinateur » : cliquer sur Informations complémentaires, puis Exécuter quand même. Windows 10 ou 11.

Télécharger pour Windows

macOS votre système

  1. Décompresser le fichier zip.
  2. Glisser Boîtes à classer dans le dossier Applications.

Au premier lancement, macOS bloque l'application : ouvrir Réglages Système → Confidentialité et sécurité, puis cliquer sur Ouvrir quand même. macOS 10.15 ou plus récent, puces Intel et Apple.

Télécharger pour macOS

Linux votre système

  1. Décompresser : tar xzf boites-a-classer-linux-x64.tar.gz
  2. Lancer boites-a-classer/boites-a-classer, ou installer.sh pour l'ajouter au menu.

Nécessite WebKitGTK (paquet libwebkit2gtk-4.1-0 sur Debian et Ubuntu).

Linux (PC) Linux ARM (Raspberry Pi)

Ce que permet le logiciel

  • Créer des boîtes, les déplacer, les agrandir et les emboîter.
  • Nommer une boîte avec un attribut : bouche, squelette interne, plumes…
  • Glisser les êtres vivants dans les boîtes ; leurs caractéristiques s'affichent au survol.
  • Vérifier la classification : les erreurs sont signalées une par une.
  • Fonctionne à la souris et au doigt sur tablette.
  • Le travail est conservé d'une séance à l'autre.
