🔒 Confidentialité

Boîtes à classer est gratuit, sans publicité et sans mesure d'audience. Voici exactement ce qu'il garde, pourquoi, et comment l'effacer.

Sans compte

  • Le travail est gardé dans le navigateur de l'appareil (pas de cookie) : il ne quitte pas l'appareil.
  • Si l'on active la sauvegarde avec un code, le travail est aussi envoyé au serveur, rangé sous une empreinte du code (le code lui-même n'est pas gardé). Les 10 dernières versions sont gardées ; tout est effacé après un an sans modification.

Avec un compte

  • Un identifiant choisi librement (sans e-mail : choisissez-le sans votre nom de famille) et un mot de passe qui ne quitte jamais l'appareil : le serveur n'en garde qu'une empreinte.
  • Le travail (10 dernières versions), les collections réussies, la date de dernière utilisation, et les sessions ouvertes (empreintes seulement).
  • Un compte inutilisé pendant un an est effacé avec son travail. On peut le supprimer soi-même à tout moment : bouton 👤 → « Supprimer mon compte ».

Élèves d'une classe

  • L'enseignant crée le compte de l'élève avec un prénom (pas de nom de famille) ; l'élève se connecte avec un code dont le serveur ne garde que l'empreinte.
  • L'enseignant voit le travail de ses élèves, leur dernière connexion et les collections réussies. Il peut changer un prénom, donner un nouveau code ou effacer un élève (avec son travail).
  • Supprimer une classe, ou le compte de l'enseignant, efface les comptes de ses élèves et leur travail.

Service client

Les messages écrits au service client sont gardés avec le compte (ou, sans compte, une empreinte d'un jeton propre au navigateur), jusqu'à un an sans nouveau message, ou jusqu'à la suppression du compte. Ne mettez pas d'informations personnelles dans les messages.

Ce qui sert à protéger le site

Pour limiter les essais de mots de passe et les abus, le serveur compte les tentatives par adresse IP, sous forme d'empreinte, pendant au plus quelques heures. Le site n'enregistre rien d'autre sur les visites.

Qui voit quoi

  • L'administrateur du site voit la liste des comptes, peut consulter un travail, répondre au service client et supprimer un compte.
  • Un enseignant ne voit que ses classes et ses élèves.
  • Les données ne sont ni vendues, ni données, ni utilisées pour de la publicité.

Où sont les données

Le site est hébergé par Cloudflare (Cloudflare Pages). La base de données est créée avec l'option qui garde les données dans l'Union européenne.
