Cette page est réservée aux enseignants : connectez-vous.

Comment un élève se connecte

  1. Il ouvre le logiciel (, ou l'application installée)
  2. bouton 👤 Se connecter
  3. « Je suis élève, j'ai un code »
  4. il tape le code de sa carte.

Son travail est alors sauvegardé sur son compte, et vous pouvez le voir ici.

Vous n'avez pas encore de classe : donnez-lui un nom ci-dessus (par exemple « CM2 A »), puis ajoutez vos élèves.

Codes à distribuer

Notez-les ou imprimez-les maintenant : pour la sécurité des élèves, ils ne seront plus affichés. Un code perdu ? « Nouveau code ».

📌 Exercices donnés à la classe

Cochez les collections à faire : vos élèves les trouvent en haut de leur liste, dans le logiciel.

Chaque élève reçoit un code personnel de 8 caractères pour se connecter.
